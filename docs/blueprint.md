# **App Name**: Cautela Control

## Core Features:

- Cadastro de Equipamentos: Cadastro de equipamentos: celulares, impressoras e rádios, com campos para informações relevantes (marca, modelo, número de série, etc.).
- Controle de Acesso: Controle de acesso de usuários com diferentes níveis de permissão (administrador, operador, etc.).
- Cadastro de Usuários: Cadastro de usuários do sistema, com informações de contato e credenciais de acesso.
- Cadastro de Cautelas: Cadastro de cautelas, registrando o policial, equipamento(s) cautelado(s), data e hora da cautela, e status (Entregue/Devolvido).
- Cadastro de Policiais: Cadastro de policiais, com informações como nome, identificação funcional, unidade, etc.
- Status da Cautela: Botões para alterar o status da cautela para 'Entregue' e 'Devolvido', com registro da data e hora da alteração.
- Relatório de Cautelas: Relatório de todas as cautelas efetuadas, com filtros por data e policial.

## Style Guidelines:

- Primary color: Saturated blue (#2962FF) to inspire confidence and trustworthiness.
- Background color: Light desaturated blue (#D2E0F7).
- Accent color: Analogous purple (#A214FF), different in saturation, for emphasis of actionable items.
- Font pairing: 'Space Grotesk' (sans-serif) for headings, and 'Inter' (sans-serif) for body text.
- Code font: 'Source Code Pro' for any displayed code (monospaced).
- Ícones claros e modernos para representar os diferentes tipos de equipamentos e ações (entrega, devolução, etc.).
- Layout limpo e organizado para facilitar a visualização das informações e o fluxo de trabalho.
- Transições suaves para indicar mudanças de status e carregamento de dados.
